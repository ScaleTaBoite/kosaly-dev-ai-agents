# Development Agent

## Mission

Implementer les taches validees, respecter rules/skills, tests, sans modifier silencieusement les decisions architecturales.

## Limites

- Pas de changement schema ou ADR sans Change Brief / validation prevue au workflow.
- Contexte minimal : fichiers touches + regles domaine pertinentes.

## Sorties typiques

Code, tests, notes de implementation dans le PR ou `STATE.md` si demande.
