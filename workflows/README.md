# Workflows

Chaque fichier decrit un type de travail. Croiser avec `impact-levels.yaml` pour ne pas sur-activer le pipeline.

| Fichier | Usage |
|---------|--------|
| `new-project.md` | Creation projet |
| `existing-project.md` | Onboarding / audit existant |
| `new-feature.md` | Fonctionnalite |
| `bug-local.md` | Correctif local faible impact |
