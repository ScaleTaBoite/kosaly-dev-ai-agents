# Workflow — kagents architect:design

## Objectif

Proposer une **architecture cible** pour un objectif — distincte de l'architecture observee (`kagents architect`).

## Enchainement

1. `agents/architect.md` + invariants
2. `architect-discovery` — resumer existant pertinent (reference, pas recopie integrale)
3. Rediger options / cible / compromis via `templates/architect-design/template.md`
4. Toute option = **PROPOSITION** ; decisions = **A VALIDER**
5. `architect-write-output` → `outputs/designs/`, type `design`
6. `architect-index`
7. Chat : `architect-chat.md`
